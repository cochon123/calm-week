# Devpost — Calm Week
**Tagline:** A student planner that shows you one thing at a time.
## Inspiration
Long to-do lists made my week feel heavier than it was. Students with ADHD, anxiety or busy work schedules told the same story: the list itself is the stress.
## What it does
You add tasks with a day and an energy level. Calm Week shows a single "Right now" task, a week grid, and a gentle heads-up when a day is overloaded. Dark, high-contrast and large-text modes are one tap away.
## How we built it
Started from a user persona and flow, then built the interface directly in HTML, CSS (custom properties for themes) and vanilla JS with localStorage. Built with help from an AI coding assistant.
## Challenges
Making three themes that all pass contrast; keeping the interface minimal while still showing the whole week.
## Accomplishments
Fully keyboard-accessible, screen-reader-friendly, and works on phones.
## What we learned
Accessibility decisions (focus, contrast, live regions) are design decisions, not add-ons.
## What's next
Drag-and-drop rescheduling, calendar import, usability tests with classmates.
## Built with
html, css, javascript, accessibility
